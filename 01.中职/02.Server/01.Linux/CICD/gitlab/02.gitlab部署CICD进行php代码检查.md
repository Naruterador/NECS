# 在gitlab主机上进行配置和安装
## 1. 安装并配置php代码检查和修复工具---phpcs、phpcbf
```shell
#安装php环境
dnf install php*

#下载phpcs
curl -L -o phpcs.phar https://github.com/PHPCSStandards/PHP_CodeSniffer/releases/latest/download/phpcs.phar

#下载phpcbf
curl -L -o phpcbf.phar https://github.com/PHPCSStandards/PHP_CodeSniffer/releases/latest/download/phpcbf.phar

##配置全局有效
chmod +x phpcs.phar phpcbf.phar
ln -s /opt/phpcs/phpcs.phar /usr/local/bin/phpcs
ln -s /opt/phpcs/phpcbf.phar /usr/local/bin/phpcbf

#验证
phpcs --version  
phpcbf --version
```


## 2. 安装 GitLab Runner
```shell
curl -L "https://packages.gitlab.com/install/repositories/runner/gitlab-runner/script.rpm.sh" -o script.rpm.sh

sudo bash script.rpm.sh

sudo dnf install -y gitlab-runner
```
#### 安装后验证
```shell
gitlab-runner --version
```

#### 启动服务
```shell
sudo systemctl enable --now gitlab-runner
sudo systemctl status gitlab-runner
```

#### 用如下指令测试
```shel
which phpcs
sudo -u gitlab-runner php -v
sudo -u gitlab-runner /usr/local/bin/phpcs --version
```
#### 注册 GitLab Runner(在需要发布的代码仓库下)
```shell
Settings
  ↓
CI/CD
  ↓
Runners
  ↓
New project runner
```

![[g7.png]]

#### 创建 Runner 后，GitLab 会给你一个注册命令或 token

#### 然后在服务器上注册gitlab-runner：
```shell
sudo gitlab-runner register

# 按照如下内容填写
GitLab instance URL:
http://你的GitLab地址/

Token:
页面上给你的 runner token

Description:
php-runner

Tags:
php

Executor:
shell
```

## 3.在网站根目录下配置 .gitlab-ci.yml
```yaml
stages:
  - code_check

phpcs_check:
  stage: code_check
  tags:
    - php
  script:
    - /usr/local/bin/phpcs --version
    - |
      find . -name "*.php" \
        -not -path "./.git/*" \
        -not -path "./vendor/*" \
        -print0 | xargs -0 -r /usr/local/bin/phpcs --standard=PSR12 -n
  only:
    - merge_requests
    - main
```
